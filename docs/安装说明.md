# 远控语音直输 · 分享版 1.0.0

在本机用豆包语音说话，让文字直接进入 UU 远控中的另一台 Mac。支持边说边显示、跟随豆包的长按与免按快捷键，不通过剪贴板粘贴。

## 首个公开版本

加入登录自启与 UU 映射自动恢复的部署支持，修复映射正常时本机页面与远控画面反复跳转的问题：先检查实际端口，正常时完全不操作窗口。也包含近期的 Electron 输入框捕获和 Qoder CN 整句字符输入兼容处理，具体应用仍需实测。

## 包里有什么

- `远控听写.app`：装在说话的本机。
- `远控直输接收端.app`：装在被控 Mac。
- `uu-remote-dictation.zip`：可选 Codex Skill，包含安装/排查流程、程序与源码。没有 Codex 也可以直接使用两个程序。
- `SHA256SUMS.txt`：文件完整性校验值。

## 使用条件

两台运行 macOS 13 或以上的 Mac；程序含 Apple Silicon 与 Intel 架构。本机自行安装豆包语音输入法，两台机器通过 UU 远程连接，并能使用其 TCP 端口映射功能。豆包和 UU 本体、账号均不在包内。

这是非官方个人工具，与豆包/字节跳动、UU/网易没有隶属关系。程序使用本地临时签名，没有开发者公证；首次打开可能需要你在系统“隐私与安全性”中确认。无需关闭系统安全保护。

## 安装配置

1. 把本机程序和接收端分别放到对应电脑的“应用程序”目录，启动各自程序。如果已有同名工具，先退出并保留旧版；不要直接覆盖来源不明或已有独立配置的同名程序。
2. 两端在菜单栏打开“配置直输配对…”。分享版端口为空，自行选择未占用的高位 TCP 端口，在接收端填写。
3. 在任一端点“生成配对码…”，把新生成的配对码填到另一端，两端保存。配对码只保存在各自系统钥匙串中，不是电脑登录密码，不要发给其他人。
4. 在 UU 为这台被控 Mac 建立端口映射：本机空闲端口 → 远端 `127.0.0.1:<接收端口>`。发送端填写本机映射端口；接收端填写远端端口。两者可以不同，只需与映射对应。保持映射在线。
5. 按系统提示给本机发送端启用“辅助功能”和“输入监控”，给接收端启用“辅助功能”。它们用于监听快捷键和向目标应用输入文字。系统要求密码时，在对应电脑上自行输入。
6. 在豆包中设置“长按模式”和“免按模式”的快捷键，两项可以不同。工具在空闲时约 1 秒自动同步；先在远端“文本编辑”空白文档测试，再尝试日常应用。

同局域网和异地都使用上述 UU 通道，无需额外开放路由器公网端口。具体连接能力取决于你的 UU 版本和网络。

## 可选：登录自启和自动恢复

接收端首次启动会注册当前用户的登录自启，可在程序菜单“开机自启”中关闭。发送端可加入 macOS 的“登录项”。自启在登录系统后生效；两端 UU 需运行，本机豆包需可用。接收端可保持后台运行，只监听本机回环地址，不需要额外云服务。

自动映射默认关闭，必须绑定你自己的 UU 目标设备与既有映射规则，不能直接套用他人的配置。安装下述可选 Skill 后，可以让 Codex 按 `references/automation.md` 完成绑定和验收；不用 Codex 也可参照该说明。绑定完成后，发送端菜单提供“连接 UU 时自动恢复语音映射”开关。

自动恢复只在对应设备正在被控制、UU 在前台且没有听写时执行。端口正常就不动窗口；连续两次确认端口关闭后才恢复。该界面适配已在中文 UU 4.45.0 验证，其他版本可能需要调整。不启用自动恢复也可继续使用手动映射。

## 怎么说话

- 轻点豆包“免按模式”的快捷键，等豆包启动后说话，再轻点一次结束。
- 或按住豆包“长按模式”的快捷键说话，松开结束。
- Esc 取消；其他键盘/鼠标操作也可能取消当前听写；轻点模式在 50 秒后自动结束。
- 本工具正常时隐藏界面，豆包自己的提示仍保留。支持实时替换的输入框会逐步显示文字，结束后用最终结果校正；不支持的输入框会等结束后整句输入。

Ctrl、Fn 的长按、轻点和连续两轮实时输入已经跨机验证。普通键及修饰键组合有自动自检覆盖，仍需在实际环境测试；Caps Lock 暂不支持。清空豆包某一模式的快捷键会禁用对应模式。豆包升级若改变设置格式，工具会提示读取失败，需要更新适配。

实时模式只替换这一轮听写的范围。听写中移动光标、切换输入框或编辑原文会停止更新。取消/断线后，如果目标已经改变，可能保留部分草稿，检查后再重试。当前真实跨机验证覆盖 macOS“文本编辑”，不保证所有网页、聊天或代码编辑器支持实时更新。

## 可选：使用 Codex Skill

解压 `uu-remote-dictation.zip`，把里面整个 `uu-remote-dictation` 文件夹放进自己电脑的 `~/.codex/skills/`。在新的 Codex 会话中说：

> 使用 $uu-remote-dictation 帮我配置两台 Mac 的远控语音输入。

Skill 中的 `assets/source/` 是完整源码，需要重建时在该目录运行 `scripts/build-app.sh`，需自行安装 Swift/Command Line Tools。`--check-shortcuts` 可只读检查当前快捷键，`--self-test` 运行 26 组自检，不向真实输入框写文字；`--check-mapping-listener` 只检查配置端口是否由 UU 监听，不读取配对码。

## 隐私与首次启动

本包不含发布者的端口配置、配对码、密码、设备名称、网络地址、个人目录、系统偏好、现场日志或测试录音/文字。端口必须自行填写，配对码必须自行生成；自动映射的目标设备和规则必须自行绑定。分享程序采用独立应用标识，不读取发布者私人版本的钥匙串条目。

正常运行时语音仍由本机豆包处理，中间文字通过配对后的加密连接传给你指定的远端接收端。本工具仅从当前使用者的豆包设置读取快捷键，不包含发布者的豆包设置文件。`127.0.0.1` 是通用本机回环地址，并非发布者的设备地址。
