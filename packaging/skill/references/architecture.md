# 实现约束

- `ControlHoldMonitor` 从豆包设置读取长按/免按快捷键，空闲时每秒同步；活动手势使用开始时的配置。轻点进入保持状态，第二次轻点释放结束；长按释放结束。等透明文本客户端获得焦点后，在 HID 层发送带自身标记的已配置快捷键事件，自身监听跳过该标记。存在长按配置时用它模拟持续按住；只有免按配置时用豆包原生免按触发。取消/失败时平衡释放按键，普通组合键保留透传。
- `ComposerTextView` 必须截获 `setMarkedText` 和 `insertText`；仅监听 `textDidChange` 会漏掉豆包中间结果。隐藏 UI 仍保留真实 NSTextView、正常文本容器宽度和输入焦点，不把整个窗口透明度降为零来代替文本客户端。
- 加密消息使用随机配对密钥、AES-GCM、长度帧及接收端会话挑战。`ready.previewSupported` 协商实时能力；旧接收端/不支持的目标只接收最终提交。
- 约 120ms 合并最新草稿，一次只等一个 `previewed` 回执；最终提交等待在途草稿回执，避免重复追加与乱序。不自动重发结果不明的文字输入。
- `DirectInputReplacement` 持有原文/选区与本轮替换范围。每次 AX 更新前后验证焦点、文本、选区；用 UTF-16 范围处理表情，不能整框覆盖原文。取消只在状态仍吻合时恢复，否则保留可能的草稿供用户检查。
- 接收端只监听回环地址。成功回执发送后不能立即取消连接：本地 contentProcessed 不代表 UU 中转已经交付。等客户端读完关闭，并对遗留连接设超时。
- 密钥只存 Keychain；可公开的源码没有预置配对码或端口。端口为 0 表示尚未配置，不能据此启动真实监听或发送。

构建：在 `assets/source/` 运行 `scripts/build-app.sh`，输出两端通用架构应用到该目录 `dist/`。分享标识为 `org.remotedictation.bridge` 和 `.Receiver`，与开发者私人版本隔离。不要复制 `.build`、系统偏好、Keychain、旧安装备份、日志、诊断采样或现场截图到再发布包。

修改后运行 `--self-test`，重点检查识别纠正、表情范围、原文保护、取消、网络回执和最终去重。自检目前包含 26 组；仍需在真实远端目标中测试语音和连续触发。

## 豆包快捷键读取与 Fn

`DoubaoShortcutSettings` 只读取当前用户豆包设置目录中 MMKV 的 `d` 设置记录，不遍历账号、录音或历史。验证元数据版本、活动长度、CRC、读取前后快照一致，取最新非删除记录，并用限定类型的安全 NSKeyedArchive 解码。只解释 `asrLongPressShortcut*`、`asrShortcut*` 的键码、标记与显示值；不要把整个设置文件复制进诊断或分享包。未知格式要报错，不能猜固定按键。

豆包当前将独立 Fn 保存为 keyCode=63、ModifierFlags=0，解析时仅为这个表示补全 Fn 标记。物理 Fn 轻点释放后已观察到额外的 keyCode=179、sourcePID=0、marker=0 的 down/up；`FnCompanionEventFilter` 只在程序已捕获 Fn 松开的 300ms 内消费附带 down，再在 500ms 内消费对应 up。过滤状态跨单次手势结束保留，防止第二次轻点的附带消息泄漏。普通 Fn、Esc、文字键、其他来源及超时事件不匹配此规则。不要把 Fn 与 Ctrl 的差异简单归因于长按时间。


## 登录自启、映射恢复与窗口焦点（1.0.0）

- `ReceiverAutoStart` 通过用户级 LaunchAgent 在登录后用 `open -a` 启动接收端。发送端可加入系统登录项。启动项保存使用者自己的安装路径，不作为发布资产复制。
- `UUSessionMonitor` 使用 UU 自带 `device status --json`，匹配运行时配置的目标 ID、connected 状态及 isControlling=true。查询超时/失败不可作为活动会话；状态查询不等同于端到端输入验证。
- **不要把映射窗口不在 AX 树中当成映射断开。** `UUMappingListenerProbe` 用 lsof 仅查询 UU 进程拥有的已配置回环监听端口；正常时直接返回，不读取或操作窗口。`UUMappingHealth` 要求连续两次明确缺失才准许恢复；检查失败、证据过期或 PID 不一致时等待。
- `UUMappingAutomation` 只在目标会话活动、UU 前台且无听写时操作既有规则。恢复期间等待已请求的映射窗口，不反复提升主窗口。仅在前台仍是程序打开的设置窗口时返回原窗口；用户切换窗口时让开。守住这一约束，避免主页面与远控窗口来回跳转。
- 自动映射的四项偏好由部署时填写；没有预设设备或规则。配置写入本机偏好，不能加入源码、Skill 或压缩包。UU 界面适配已在 4.45.0 验证，其他版本或界面语言需要实测。

## Electron 输入框

只在目标为 Electron 且初次输入焦点捕获失败时启用其 AXManualAccessibility，再限时重试；仍检查原 PID、窗口、普通文本角色与会话有效性。Qoder CN 的编辑器可能声称 AX 文本可写却不接收写入，且第一轮之后能力报告会改变；对该已知应用固定使用最终整句 Unicode 字符输入，所有轮次一致，不使用剪贴板，不承诺实时预览。该兼容修改已包含在源码；具体目标仍须连续两轮实际验证。
